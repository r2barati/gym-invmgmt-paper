Overview

Same contract, different stress

Head-to-head inventory results depend on the test conditions almost as much as on the policy. gym-invmgmt evaluates optimization, heuristic, reinforcement-learning, imitation and LLM controllers under one shared contract: the same transition dynamics, reward, action bounds and KPIs. It then varies the stress conditions, including network topology, demand dynamics, customer goodwill and shortage handling, across a 22-scenario main grid plus four multi-agent rows.

BlockScenariosWhat varies
A · Core grid162 networks (base, serial) × 2 demand regimes (trend + seasonal, with or without shock) × goodwill on/off × backorders vs lost sales
B · Stationary replication4Stationary demand, 2 networks × backorders vs lost sales, matching the OR-Gym lineage
D · Walmart M52Real volatile demand trace from the M5 dataset on both networks
C · Multi-agent (supplementary)4Each node acts independently; 2 networks × 2 demand regimes, backorders

Get started

Run it in two minutes

Install the environment

The standalone package registers two Gymnasium environments.

pip install gym-invmgmt
import gymnasium as gym
import gym_invmgmt  # registers the environments

env = gym.make("GymInvMgmt/MultiEchelon-v0")
obs, info = env.reset(seed=0)
for t in range(30):
    action = env.action_space.sample()  # your policy here
    obs, reward, terminated, truncated, info = env.step(action)

Reproduce the paper

Download the released checkpoints and rerun the canonical benchmark.

git clone https://github.com/r2barati/gym-invmgmt-paper
cd gym-invmgmt-paper
pip install -e ".[all]"
bash download_weights.sh

cd benchmarks
python3 run_benchmarks.py --agent ALL --seeds 10
python3 verify_publication_ready.py --quick

Add an agent with a get_action(obs, t) method to agents/, register it in benchmarks/run_benchmarks.py, and run it across all 26 scenarios with --agent YourAgent.
